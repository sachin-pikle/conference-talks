### Practical Python AI on the JVM with GraalPy and Pyronaut

**25 November 2026 | 16:50–17:20 | Stage 4**

Explores two ways to bring Python’s AI and data science ecosystem to JVM applications: embedding Python with GraalPy in a Micronaut application, and building Python applications with Pyronaut, a framework built on GraalPy and Micronaut.
